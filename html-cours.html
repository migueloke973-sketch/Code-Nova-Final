Bienvenue dans HTML & CSS

HTML sert à structurer le contenu d'une page. CSS permet de contrôler son apparence, ses espaces, ses couleurs et sa mise en page.

Les premières balises

Une page commence généralement avec une structure HTML contenant un titre, des paragraphes et des sections.

<h1>Bonjour CodeNova</h1>
<p>Ma première page web.</p>

Ajouter du style

CSS permet de transformer cette structure en interface visuelle.

body {
  background: #050816;
  color: white;
}

Mini-exercice
